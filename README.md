# Sala-de-Leitura-do-Estado-de-Sao-Paulo

Este projeto integrador foi desenvolvido como parte do curso da UNIVESP e tem como objetivo criar uma ferramenta para organização e gerenciamento das informações da Sala de Leitura da Escola Estadual J.A. buscando facilitar o cadastro e a consulta dos livros, o controle dos empréstimos e das devoluções e o gerenciamento dos dados dos usuários, substituindo os procedimentos manuais por uma ferramenta digital prática, organizada e de fácil utilização.
