# Sala-de-Leitura

Este projeto integrador foi desenvolvido como parte do curso da UNIVESP e tem como objetivo criar uma ferramenta para organização e gerenciamento das informações da Sala de Leitura da Escola Estadual J.A. buscando facilitar o cadastro, consulta dos livros, controle dos empréstimos, devoluções e gerenciamento dos dados dos usuários, substituindo os procedimentos manuais por uma ferramenta digital mais prática, organizada e de fácil utilização.
